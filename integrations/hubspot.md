# HubSpot Integration

## Purpose
AI can access HubSpot to pull deal data, contact info, activity history, and pipeline status for analysis and action.

## Key Data Available
- Active deals and stages
- Contact records (name, role, company, email)
- Activity log (calls, emails, meetings)
- Deal notes
- Pipeline by stage and value
