# /brief — Create Project or Engagement Brief

## Trigger
User types: `/brief for [project/client/engagement]`

## What to Do

1. **Load client/prospect context** if applicable
2. **Load brief template** — Read `/brain/templates/project-brief.md`
3. **Determine brief type**:
   - Client engagement brief (Toptal placement)
   - Teaching program brief (new course/workshop)
   - Internal project brief

## Build the Brief

### For Toptal Client Engagement
1. **Client**: Name, industry, size
2. **Engagement Goal**: What success looks like for them in 90 days
3. **Role/Talent Required**: Exact profile, skills, experience level
4. **Timeline**: Start date, duration, hours/week
5. **Budget**: Range and flexibility
6. **Key Stakeholder**: Who manages the talent day-to-day
7. **Success Metrics**: How we'll know it worked
8. **Risks / Watch-outs**: What could go wrong

### For Teaching Program
1. **Program Name + Track**: AI for Sales / Sales for AI
2. **Audience**: Who exactly (role, experience level, industry)
3. **Learning Outcome**: 3 things they can DO after the program
4. **Format**: Workshop / cohort / async / 1:1 coaching
5. **Duration + Schedule**: Length and cadence
6. **Curriculum Outline**: Module list with brief description
7. **Materials Needed**: Slides, exercises, tools
8. **Revenue Model**: Pricing, seats, delivery cost

## Output
Complete brief document, ready to send or file.
