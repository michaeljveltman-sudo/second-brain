# /pipeline — Pipeline Review & Prioritization

## Trigger
User types: `/pipeline` or `/pipeline review this week`

## What to Do

1. **Load pipeline data** — Check `/pipeline/` folder for deal files
2. **Load qualification framework** — Read `/brain/frameworks/qualification-framework.md`
3. **Load Toptal sales process** — Read `/brain/frameworks/toptal-sales-process.md`
4. **Check calendar context** — If calendar integration is set up, pull this week's meetings

## Build the Review

### 1. Pipeline Health Summary
For each open deal:
- Company name | Stage | Deal size | Close date | Last activity | Next step

### 2. Priority Stack Rank This Week
Rank deals by: (urgency × deal size × win probability)
Flag:
- Deals at risk (no activity in 7+ days)
- Deals with imminent close dates
- Deals stuck in same stage for 14+ days

### 3. Recommended Actions This Week
For each top-5 deal: one specific action to advance it.

### 4. Deals to Deprioritize or Disqualify
Honest assessment — which deals are wasting time?

### 5. Coaching Observations (if team pipeline)
Patterns across the team — what's working, what needs coaching?

## Output Format
Table + bullet points. Focus on actions, not just status.
Ask: "Want me to draft the next action email or prep for any of these calls?"
